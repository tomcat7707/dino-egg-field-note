# 공룡알 화석산지 현장노트

2026년 9월 13일 화성 고정리 공룡알 화석산지를 직접 걸으며 촬영한 사진으로 만든 모바일 퍼스트 현장 기록 웹페이지입니다.

## 주요 구성

- 방문자센터에서 누드바위까지 이어지는 탐방 스토리
- 직접 촬영한 사진 10장과 확대 보기
- 화성의 뿔공룡 `Koreaceratops hwaseongensis` 소개
- 방문자센터 2층에서 본 먼 건물에 대한 미해결 관찰
- 짧은 현장 퀴즈

## 실행

별도의 설치 없이 `index.html`을 열면 됩니다. GitHub Pages에서는 저장소 루트의 파일을 그대로 배포할 수 있습니다.

## 자료

사진은 저장소 소유자가 현장에서 직접 촬영했습니다. 기본 정보는 화성특례시 및 국가유산청 공식 자료를 참고했습니다.
